## 🖥️ Command Line Interface

### **Command Groups**

#### Network
```bash
sec-llama network discover    # Host discovery
sec-llama network scan         # Port scanning
sec-llama network vuln-scan    # Full vulnerability scan
```

#### Traffic
```bash
sec-llama traffic analyze      # PCAP analysis
sec-llama traffic capture      # Live capture
sec-llama traffic find-creds   # Credential search
```

#### Wireless
```bash
sec-llama wireless scan        # WiFi scanning
```

#### Code
```bash
sec-llama code scan           # Code vulnerability scan
```

#### Pentesting
```bash
sec-llama pentest attack-plan  # Attack planning
sec-llama pentest exploit      # Exploit suggestions
sec-llama pentest payload      # Payload generation
```

#### Threat Intel
```bash
sec-llama threat cve           # CVE lookup
sec-llama threat cve-search    # CVE search
sec-llama threat ioc           # IOC analysis
```

#### Multi-Agent 🆕
```bash
sec-llama agent collab-assess  # Collaborative assessment
sec-llama agent status         # Agent status
```

#### Log Analysis 🆕
```bash
sec-llama logs analyze         # Log analysis
sec-llama logs find-attacks    # Attack detection
```

#### Incident Response 🆕
```bash
sec-llama incident create      # Create incident
sec-llama incident contain     # Execute containment
```

#### Code Review 🆕
```bash
sec-llama review commit        # Review commit
sec-llama review pr            # Review pull request
sec-llama review file          # Review file
```

#### Container Security 🆕
```bash
sec-llama container scan-image     # Scan Docker image
sec-llama container scan-running   # Scan running containers
```

#### API Security 🆕
```bash
sec-llama api fuzz             # Fuzz API endpoint
sec-llama api test-auth        # Test authentication
```

#### Reporting 🆕
```bash
sec-llama report generate      # Generate report
```

#### Utilities
```bash
sec-llama ask                  # Natural language queries
sec-llama config               # Configuration
sec-llama doctor               # Dependency check
sec-llama version              # Version info
```
